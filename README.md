## Overview

Welcome to the **Real-Time Location Tracker** project! This web application enables real-time location tracking using WebSocket technology. It displays live locations on an interactive map, allowing all connected users to view one another in real time.

## Features

- **Real-time Location Updates**: Uses WebSocket technology for instant, live location synchronization.
- **Interactive Map**: Displays dynamic locations using OpenStreetMap and Leaflet.js.
- **Multi-user Support**: Enables multiple connected users to share and view locations simultaneously.

## Technologies Used

- **JavaScript**: Used for both client-side and server-side logic.
- **Node.js**: JavaScript runtime built on Chrome's V8 engine.
- **Express.js**: A minimalist web framework for Node.js applications.
- **Socket.IO**: Enables real-time, bidirectional communication between server and clients.
- **OpenStreetMap**: Provides map data.
- **Leaflet.js**: JavaScript library for interactive, mobile-friendly maps.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/realtime-location-tracker.git
    ```
2. Navigate to the project directory:
    ```bash
    cd realtime-location-tracker
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Start the server:
    ```bash
    node app.js
    ```
2. Open your browser and go to:
    ```
    http://localhost:3000
    ```
